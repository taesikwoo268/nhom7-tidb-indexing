\subsection*{A. Lệnh chạy lại thí nghiệm}
\addcontentsline{toc}{subsection}{A. Lệnh chạy lại thí nghiệm}

Các lệnh chạy trong thư mục gốc của dự án, trên PowerShell. Nếu một lượt đo bị ngắt, chạy lại đúng lệnh đó để đo tiếp phần còn thiếu.

\begin{lstlisting}[caption={Lệnh PowerShell chạy lại các thí nghiệm}]
.venv\Scripts\python -m bench.cli check

# RQ1: 1 trieu dong (M3) va 3 trieu dong (M2, M1)
.\scripts\rq1_official.ps1
.\scripts\rq1_official.ps1 -Rows 3000000
.venv\Scripts\python -m experiments.rq1_summary results/rq1_M3.csv

# RQ4: 84 luot (M2)
.\scripts\rq4_official.ps1

# RQ4: 36 luot MySQL voi utf8mb4_bin, cung collation voi TiDB
$env:PROFILE = "XS"; $env:DB_NAME = "logistics_bin"   # database tao voi COLLATE utf8mb4_bin
.venv\Scripts\python -m bench.cli rq4 mysql 1000000 --seconds 60 --reps 3 --threads 64 --indexes 0 1 3 5 sender_created sender_cov --mode insert update --output results/rq4_official_mysql_bin.csv
.venv\Scripts\python -m experiments.rq4_summary results/rq4_official_bin.csv --figure results/fig/rq4_tps_vs_indexes_bin.png

# Demo (project Docker rieng nhom7demo)
.\scripts\demo.ps1 co_ban_mysql
.\scripts\demo.ps1 chiu_loi_mysql
.\scripts\demo.ps1 co_ban_tidb
.\scripts\demo.ps1 chiu_loi_tidb
.\scripts\demo.ps1 them_node
\end{lstlisting}
